O que eu abro

O navegador serve para enxergar a Central. O terminal serve para registrar fatos. Essa separacao evita mexer sem querer no livro-razao.

Painel geral Abra `dashboard/index.html` para ver projetos, pendencias, itens aguardando preco e aprendizados.
Projeto da compra Entre em `projetos/<ano>-<compra>` para ler briefing, ranking, validacao e decisao.
Terminal Rode `status` sempre que nao souber o proximo passo. Ele mostra bloqueios e comando sugerido.
dashboard/index.htmlPainel visual da Central.
projetos/.../briefing.mdO que voce quer, teto, urgencia e criterios.
projetos/.../cotacoes.csvPreco datado. Nao edite linha antiga; preco novo vira linha nova.
projetos/.../ranking.mdGates, score, confianca e motivo de corte.
projetos/.../decisao.mdEscolhido, motivo e por que os outros perderam.
vereditos/D+30 e D+180: a compra realmente deu certo?
abrir painel 
cd C:\projetos\central-compras
python scripts\central_compras.py dashboard
start .\dashboard\index.html

Regras de ouro

Se lembrar so disto, voce ja usa a Central com seguranca.

Nao apague fato antigo Preco novo e linha nova. O historico e parte da decisao.
Web nao fecha compra Cotacao web ajuda a pesquisar. Decisao final exige confirmacao manual.
Gate vem antes do score Produto reprovado nao ganha porque tirou numero bonito.
Perdedor tambem tem motivo Registrar por que nao escolheu evita refazer pesquisa no futuro.

Roteiro clicavel

Clique em uma etapa para ver o comando principal e o que ela produz.

Checar estado

Antes de mexer, veja se o repo esta limpo e se o CLI responde.

ponto de partida
comando 
cd C:\projetos\central-compras
git status --short --branch
python scripts\central_compras.py --help

Quando chega no ranking

O ranking nao e uma ordem para comprar. Ele te joga para uma destas tres saidas.

Descartar

Falhou em gate, passou do teto ou perdeu por motivo claro.

comando
python scripts\central_compras.py descartar --produto-id anker-q30 --projeto projetos\2026-fone-bluetooth-para-chamadas --porque "Melhor ANC, mas passou do preco teto confirmado."
Aguardar preco

Produto aprovado, mas ainda acima do preco que faz sentido.

comando
python scripts\central_compras.py aguardar-preco --produto-id qcy-h3-anc --projeto projetos\2026-fone-bluetooth-para-chamadas --preco-alvo 260 --preco-teto 330 --porque "Aprovado, mas vale esperar desconto."
Comprar

Tem cotacao manual fresca, confianca suficiente e motivo dos perdedores.

comando
python scripts\central_compras.py decidir projetos\2026-fone-bluetooth-para-chamadas --produto-id qcy-h3-anc --porque "Melhor equilibrio entre preco confirmado, microfone, conforto e garantia." --perdedores "anker-q30: passou do preco teto; jbl-770nc: menos vantagem pelo custo" --comprado

Compra atual do fone

A Central ja apontou o caminho: a pesquisa existe, mas falta confirmacao manual. Comece pelo lider e pelo segundo colocado.

status da compra
cd C:\projetos\central-compras
python scripts\central_compras.py status projetos\2026-fone-bluetooth-para-chamadas
confirmacao manual
python scripts\central_compras.py promover-cotacao projetos\2026-fone-bluetooth-para-chamadas --produto-id qcy-h3-anc --preco VALOR --frete VALOR --garantia-meses 12 --garantia-tipo nacional --link "LINK_ATUAL"
validar e abrir ranking
python scripts\central_compras.py validar projetos\2026-fone-bluetooth-para-chamadas
python scripts\central_compras.py ranking projetos\2026-fone-bluetooth-para-chamadas
python scripts\central_compras.py auditar projetos\2026-fone-bluetooth-para-chamadas
start .\projetos\2026-fone-bluetooth-para-chamadas\ranking.md

Depois da compra

A memoria que vale ouro nasce no D+30 e no D+180: voce descobre se a decisao foi boa, se a marca presta e se a loja merece confianca.

decisao.mdO motivo da escolha fica registrado.
snapshots/Ranking e cotacao do dia ficam congelados.
veredito D+30Chegou certo? Defeito? Loja resolveu?
veredito D+180Durou? Valeu o preco? Compraria de novo?
D+30
python scripts\central_compras.py preencher-veredito vereditos\2026-09-25-projeto-produto.md --fase d30 --nota-arrependimento 1 --compraria-de-novo sim --resumo "Chegou certo e resolveu chamadas." --chegou-no-prazo sim --produto-conforme sim --defeito nao --licao "Compraria de novo de vendedor confiavel."
python scripts\central_compras.py aprender-veredito vereditos\2026-09-25-projeto-produto.md --fase d30
